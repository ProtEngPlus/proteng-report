**Instructions for Using the Proposal Template**

**1\. Structure**

* Follow the **template sections in order** (Basic Information → Abstract → Introduction → Problem Solving → Design → Teamwork → Timeline → Ethics → References).

* Include a **Table of Contents** with correct page numbers.

* Ensure **page numbering** is continuous throughout the document.

* Use **clear section headings and subheadings** so evaluators can easily locate information.

**2\. English**

* Write in **formal academic English** that is clear, concise, and grammatically correct.

* Avoid casual language, bullet-only descriptions, or incomplete sentences.

* Use consistent tense and style throughout the report.

**3\. Figures and Diagrams**

* All diagrams must be **accurate, clear, and directly related** to the content.

* Each figure or diagram must have a **number, title, and caption** (e.g., *Figure 1: System Architecture*).

* Refer to all figures in the main text (e.g., *as shown in Figure 1*).

* Ensure diagrams are **readable when printed** (labels not too small).

**4\. References**

* Use a **consistent referencing style** (IEEE or APA recommended).

* Every in-text citation must have a corresponding entry in the References section.

* References must include **complete details** (authors, title, publication, year, etc.).

* Reference format must be **consistent throughout** the document.

**5\. Citation and Academic Honesty**

* Cite **all sources properly**, including figures, diagrams, data, and text.

* Direct quotations must be placed in quotation marks and cited.

* Use plagiarism-check tools (e.g., Turnitin via Capstone account) before submission.

* Failure to cite properly or submitting plagiarized work will result in rejection of the proposal.
